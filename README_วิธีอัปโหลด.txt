Q SMART SCANNER — ชุดไฟล์สำหรับ GitHub Pages

อัปโหลดไฟล์ทั้ง 6 ไฟล์ที่อยู่ในโฟลเดอร์นี้ไปยังหน้าแรก (root) ของ Repository ใหม่:
1. index.html
2. apple-touch-icon.png
3. icon-192.png
4. icon-512.png
5. manifest.webmanifest
6. sw.js

หมายเหตุ: README_วิธีอัปโหลด.txt เป็นคู่มือ จะอัปโหลดเพิ่มก็ได้ แต่ไม่จำเป็นต่อการทำงาน

วิธีเผยแพร่
1. GitHub → New repository → ตั้งชื่อ เช่น q-smart-scanner → Create repository
2. Add file → Upload files → เลือกทั้ง 6 ไฟล์ (ไม่ต้องอัปโหลด ZIP) → Commit changes
3. Settings → Pages → Build and deployment: Deploy from a branch → Branch: main, /(root) → Save
4. รอ GitHub Pages แสดงลิงก์เว็บไซต์ แล้วเปิดลิงก์ใน Safari
5. Safari → Share (แชร์) → Add to Home Screen (เพิ่มไปยังหน้าจอโฮม)

วิธีใช้งาน
- สแกนเอกสารหรือเลือกรูปจากเครื่อง
- ถ้าขอบตรวจจับไม่แม่น ให้ลากวงกลมสีเขียวทั้ง 4 จุดให้ตรงมุมกระดาษ
- กด ตัดและปรับให้ตรง → เลือกโหมดสี → เก็บหน้านี้
- เพิ่มหน้าได้ แล้วบันทึก PDF รวมทุกหน้า หรือ JPG เฉพาะหน้าที่เลือก

ข้อควรทราบ
- จำเป็นต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลด OpenCV.js (ตรวจจับขอบและดึงมุม) และ jsPDF (บันทึก PDF) จากบริการภายนอก; ไอคอนและหน้าเว็บถูกแคชไว้บางส่วน แต่ไม่ได้รับประกันการทำงานออฟไลน์เต็มรูปแบบ
- กรณี OpenCV.js โหลดไม่สำเร็จ สามารถปรับมุมด้วยนิ้วได้ แต่การแก้ภาพใช้วิธีใกล้เคียง ไม่ใช่ perspective transform เต็มรูปแบบ
- เอกสารที่สแกนเก็บอยู่ในหน่วยความจำของหน้าเว็บระหว่างเปิดใช้งาน ไม่ใช่คลังไฟล์ถาวร อย่าปิดหน้าเว็บก่อนบันทึก
- ไฟล์ JPG จะบันทึกเฉพาะหน้าที่เลือก และ PDF จะรวมทุกหน้าที่เก็บไว้
